Cada ejemplo es un workflow real contra una API pública que no pide cuenta: [DummyJSON](https://dummyjson.com), [PokéAPI](https://pokeapi.co) o [JSONPlaceholder](https://jsonplaceholder.typicode.com). Tienes el contrato y el archivo Arazzo, listos para ejecutar.

<Aside type="tip" title="Probados antes de publicarse">
Cada ejemplo de estas páginas se ejecuta con el motor de Luvin contra la API real antes de publicar la documentación. Los status y valores que ves son los que obtuvo.
</Aside>

## Abre un ejemplo

<Steps>

1. Descarga los archivos del ejemplo (los botones al principio de cada página).
2. En Luvin, abre o crea una colección y elige **Importar Arazzo o contratos**. Elige los archivos descargados.
3. Abre el workflow en la barra lateral, elige **API real** y pulsa **Ejecutar**.

</Steps>
