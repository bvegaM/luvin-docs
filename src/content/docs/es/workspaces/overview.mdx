Un **workspace** es la carpeta que contiene todo tu trabajo. Dentro, cada **colección** es una subcarpeta para un tema: un partner, un producto, una familia de APIs. Necesitas un workspace en cuanto quieres que Luvin conserve lo que construyes.

![El inicio del workspace, con sus colecciones, las acciones rápidas y el panel de documentación](/media/es/home.webp)

## La jerarquía

<FileTree>

- mi-workspace/ el workspace
  - luvin.yaml la lista de colecciones
  - README.md la documentación del workspace (opcional)
  - pokedex/ una colección
    - collection.yaml su nombre, versión y autorización
    - README.md la documentación de la colección (opcional)
    - pokeapi.openapi.yaml un contrato
    - pokemon.arazzo.yaml un archivo Arazzo con workflows
    - environments/
      - local.yaml un ambiente
    - scenarios/ los inputs y casos de cada Arazzo
    - requests/ los requests guardados
  - partners/ otra colección

</FileTree>

Todo son archivos de texto, así que puedes guardar el workspace en git. [Qué hay en el disco](/es/workspaces/files/) explica cada archivo.

## Workspace y colección

| | Workspace | Colección |
|---|---|---|
| **Qué es** | La carpeta que contiene colecciones. | Una subcarpeta para un tema. |
| **Archivo que la describe** | `luvin.yaml` | `collection.yaml` |
| **Qué contiene** | La lista de colecciones y un README opcional. | Contratos, archivos Arazzo, ambientes, casos, requests, una autorización y un README opcional. |
| **Cuántas** | Trabajas en uno a la vez. | Una o muchas por workspace. Hay una abierta a la vez. |

Cada uno tiene su propia documentación, un `README.md`. Mira [Escribir documentación](/es/workspaces/documentation/).

## Cómo guarda Luvin tu trabajo

Nunca presionas Guardar. Medio segundo después de tu último cambio, Luvin escribe solo los archivos que cambiaron. La barra superior muestra el estado:

| Ves | Significa |
|---|---|
| **Guardando…** | Luvin está escribiendo archivos. |
| **✓ Guardado** | Todo está en el disco. |
| **Error al guardar** | Algo no se pudo escribir. Pasa el cursor sobre la insignia para leer el motivo. |

En los editores (un ambiente, un request) el mismo estado aparece como **Cambios sin guardar…**, **Guardando…**, **Guardado** y luego **Guardado automáticamente**. Si falla, ves **No se pudo guardar** y **Reintentar**. **⌘S** (**Ctrl+S**) guarda al instante.

Luvin también guarda antes de cambiar de colección o cerrar el workspace. Guardar nunca borra un archivo Arazzo ni un contrato. Los ambientes y requests que eliminas en la app se eliminan del disco.

<Aside type="note" title="¿Sin workspace?">
Puedes abrir archivos para una prueba rápida sin workspace. Entonces no se escribe nada en el disco. Mira [Usar Luvin sin workspace](/es/workspaces/without-workspace/).
</Aside>
