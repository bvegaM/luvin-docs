Las APIs responden estados que su contrato nunca menciona: un 429 cuando envías demasiadas peticiones, un 500 cuando el servidor se rompe, un 503 durante un mantenimiento. Las filas de **Si falla** solo listan lo que el contrato documenta, así que estos tienen su propia entrada: **+ Si responde otro status…**.

## Ejemplo: reintenta un 429 de getPokemon

El contrato de la PokéAPI documenta 200 y 404 para `GET /pokemon/{idOrName}`, no 429.

<Steps>
1. En la pestaña **Diseño** de **Pokemon card**, busca la tarjeta de `getPokemon`.
2. Al final de su sección **Si falla**, haz clic en **+ Si responde otro status…**. Aparece un campo pequeño, con `429` de ejemplo.
3. Escribe `429`.
4. Haz clic en **Elegir**, o pulsa Enter. Se abre el menú **Si responde 429**.
5. Haz clic en **Reintentar (hasta 3 veces)**.
</Steps>

![La sección Si falla de la tarjeta de getProduct, debajo de la fila 404 → sin acción, con 429 escrito en el campo y el botón Elegir](/media/es/design-branch-other.webp)

<Tabs>
<TabItem label="En la tarjeta">

Aparece una fila nueva debajo de las demás: `429 → on429` **reintenta ×3**, con un lápiz para cambiarla.

</TabItem>
<TabItem label="En el YAML">

```yaml title="pokemon.arazzo.yaml" {7-13}
- stepId: getPokemon
  # …
  onFailure:
    - name: pokemonNotFound
      type: end
      criteria:
        - condition: $statusCode == 404
    - name: on429
      type: retry
      retryAfter: 1
      retryLimit: 3
      criteria:
        - condition: $statusCode == 429
```

</TabItem>
</Tabs>

## Qué estados puedes escribir

| Regla | Detalle |
|---|---|
| Tres dígitos | El campo acepta solo dígitos, hasta tres. Las letras y los espacios se descartan mientras escribes. |
| De 100 a 599 | El primer dígito tiene que ser del 1 al 5. **Elegir** sigue desactivado hasta que el estado es válido. |
| Cualquier estado de ese rango | También 2xx y 3xx. Una rama solo se activa cuando el paso falla, así que un estado que ya cuenta como éxito nunca llega a ella. |

Para salir del campo sin elegir, pulsa **Esc**, o haz clic fuera de él con el campo vacío.

## Estados frecuentes

| Estado | Qué suele significar | Una rama razonable |
|---|---|---|
| 429 | Demasiadas peticiones | **Reintentar (hasta 3 veces)**. Sube `retryAfter` en el YAML si la API pide esperar más. |
| 500 | El servidor falló | **Terminar el workflow**, si tu aplicación muestra una página de error conocida, o ninguna rama, para que la ejecución falle y lo veas. |
| 503 | Servicio no disponible, por ejemplo durante un mantenimiento | **Reintentar (hasta 3 veces)**, o **Terminar el workflow**. |

Luvin espera solo lo que dice `retryAfter`. No lee un header `Retry-After` de la respuesta.

## Qué ves después

| Dónde | Qué aparece |
|---|---|
| La tarjeta | La fila `429 → on429` con su efecto, y un lápiz para cambiarla o quitarla. |
| El panel del paso | **Si responde con error** ahora tiene una fila **429**, con la acción elegida. |
| **Cobertura de respuestas**, en **Resumen** | Nada nuevo. La cobertura solo cuenta los estados que documenta el contrato. |
| **Casos** | Un caso generado, **getPokemon responde 429 → on429**, que simula esa respuesta. |
| Resultados de una ejecución real que recibió un 429 | La pestaña **Contrato** del paso indica **El código 429 no está documentado en el contrato de `GET /pokemon/{idOrName}`.** |

El último mensaje es un aviso, no un error de tu workflow. Si la API de verdad responde ese estado, agrégalo al contrato. Una vez documentado, aparece como una fila normal con su descripción.

<Aside type="note">
Si escribes un estado que el contrato sí documenta, o uno que ya tiene una acción, el menú se abre igual. Si ya hay una acción, el menú incluye **Quitar la rama**.
</Aside>

## Solución de problemas

**No aparece el enlace + Si responde otro status….** El paso llama a otro workflow, es un paso de mensajería o su operación no está en un contrato. Escribe la acción en la [pestaña YAML](/es/design/arazzo-editor/).

**Elegir sigue desactivado.** El estado tiene menos de tres dígitos, o empieza con 0, 6, 7, 8 o 9.

**El campo se cerró solo.** Se cierra cuando pierde el foco estando vacío. Haz clic otra vez en el enlace.
