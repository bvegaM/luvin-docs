Each example is a real workflow against a public API that needs no account: [DummyJSON](https://dummyjson.com), [PokéAPI](https://pokeapi.co) or [JSONPlaceholder](https://jsonplaceholder.typicode.com). You get the contract and the Arazzo file, ready to run.

<Aside type="tip" title="Tested before publishing">
Every example on these pages is run with Luvin's engine against the real API before the docs are published. The statuses and values you see are the ones it got.
</Aside>

## Open an example

<Steps>

1. Download the files of the example (the buttons at the top of each page).
2. In Luvin, open or create a collection and choose **Import Arazzo or contracts**. Pick the downloaded files.
3. Open the workflow in the sidebar, choose **Real API** and press **Run**.

</Steps>
