<Aside type="caution" title="Real API or Simulation: know which one passed">
With **Real API**, Luvin calls your API. With **Simulation**, it calls nothing and answers with the examples in your contracts. A case that passes in simulation proves the workflow's logic, not your API. Each result says which one it ran against. See [Simulation](/test/simulation/).
</Aside>

## Your workflow isn't locked into Luvin

Every workflow is saved as a standard [Arazzo](https://spec.openapis.org/arazzo/latest.html) file, the OpenAPI Initiative's format for sequences of API calls. It is a readable YAML file in your folder: review it in a pull request, version it next to your code, and take it to other tools that read Arazzo, such as linters or a CI runner. If you stop using Luvin, your workflows stay with you. See [The Arazzo file](/design/arazzo-file/).
